默认 f 为复函数，u,v 为实部和虚部的二元函数

解析

如果 f(z) 在 X 上解析，当且仅当 ∀z0∈X,limz→z0⁡f(z)−f(z0)z−z0 存在且唯一

格林公式

对于分段光滑（可以分成有限段光滑曲线）简单（不自交）闭曲线 C 围成的图形 D，若 P(x,y),Q(x,y) 在 D 上具有连续的一阶偏导数，且 C 取正向（逆时针方向），则

∮CPdx+Qdy=∬D(∂Q∂x−∂P∂y)dxdy

将 D 切割为有限个互不重叠的有界区域，满足这些区域都是凸的。将这些区域的格林公式相加，边界抵消。

引理一

∮Pdx=−∬D∂P∂ydxdy
因为 D 是凸的，那么 D={(x,y)|a≤x≤y,ϕ1(x)≤y≤ϕ2(x)}

−RHS=∫ab[∫ϕ1(x)ϕ2(x)∂P∂ydy]dx=∫ab[P(x,ϕ2(x))−P(x,ϕ1(x))]dxLHS=∫abP(x,ϕ1(x))dx−∫baP(x,ϕ2(x))dx=−∫ab[P(x,ϕ2(x))−P(x,ϕ1(x))]dx=RHS
引理二

∮Qdy=∬D∂Q∂ydxdy
与引理一类似，证略

两式相加即可

柯西-黎曼（C-R）方程

设 f=u+iv 解析，由定义，得：

∀z=x+yi,limΔx→0⁡u(x+Δx,y)−u(x,y)+i(v(x+Δx,y)−v(x,y))x=limΔx→0⁡u(x,y+Δx)−u(x,y)+i(v(x,y+Δx)−v(x,y))iΔx=f′(z)

即 ux+ivx=vy−iuy
即 ux=vy 且 uy=−vx
只有在满足C-R方程且偏导数连续的函数才是解析的

柯西-古萨定理（受限）

如果 f 在单连通区域 X 内解析且 f′ 连续，那么对于任意分段光滑简单闭合曲线 C∈X，∮Cf(z)dz=0
令 f(z)=u(x,y)+iv(x,y)，dz=dx+idy
f(z)dz=(u+iv)(dx+idy)=(udx−vdy)+i(vdx+udy)
设 C 围成的区域为 D
对于实部，=∬D(∂(−v)∂x−∂u∂y)dxdy
对于虚部，=∬D(∂u∂x−∂v∂y)dxdy
根据C-R方程可得以上两式均为 0

柯西-古萨定理（即柯西积分定理）

如果 f 在单连通区域 X 内解析，那么对于任意简单闭合曲线 C∈X，∮Cf(z)dz=0
显然任意简单闭合曲线都可以被若干个三角形逼近。三角形边界重合处积分抵消，所以证明每个三角形边界积分为 0
反设其积分 =M≠0，连接其中位线，分成四个小三角形。至少一个三角形边界积分的绝对值 ≤M4
对这个小三角形重复以上过程，得到三角形序列 Δn，则 |∮Δn边界f(z)dz|≥M4n
设这些三角形收敛于 z0
f(z)=f(z0)+f′(z0)(z−z0)+ι(z)(z−z0)，其中当 z→z0 时 ι→0
注意到前两项为一次函数，原函数显然存在，在闭合曲线上积分为 0
|∮f(z)dz|=|∮ι(z)(z−z0)dz|
对于任意 ε>0，存在 n，使得在 Δn 上 |ι(z)|>ε
假设第 i 个三角形的周长 Ln=L2n，直径（最长内接线段） dn=d2n
|z−z0|≤dn
RHS≤|∮|ι(z)|×|z−z0|×|dz||<ϵ×d2n×L2n=ϵ×dL4n
但是 |∮Δn边界f(z)dz|≥M4n
而 ϵ 可以任意小
证毕

复连通区域柯西积分定理

对于区域内带洞的情况，拆成多个单连通区间即可

柯西积分公式

如果 f 在闭合曲线 C 内部即边界上解析，则 ∀a 在 C 内部

f(a)=12πi∮Cf(z)z−adz

定义辅助函数

g(z)={f(z)−f(a)z−az≠af′(a)z=a

显然 g(z) 在 C 内及边界是解析的。此时称 a 为可去奇点
应用柯西-古撒定理：
∮Cg(z)dz=0
∮Cf(z)−f(a)z−adz=0
∮Cf(z)z−adz=f(a)∮C1z−adz
接下来找到以 a 为圆心且在 C 内部的圆 γ，对 C 和 γ 之间的部分使用复连通区域柯西积分定理
令 z=a+reiθ
dz=ireiθdθ
∮C1z−adz=∮γ1z−adz=∫02π1reiθireiθdθ=2πi
代回，证毕

柯西导数公式

如果 f 在闭合曲线 C 内部即边界上解析，则 ∀a 在 C 内部 ，f 在 a 点的任意阶导数导数存在且满足

f(n)(a)=n!2πi∮Cf(z)(z−a)n+1dz

对 n 归纳
当 n=0 是即为柯西积分公式
假设 n=k 成立，则

f(k)(a)=k!2πi∮Cf(z)(z−a)k+1dzf(k+1)(a)=limh→0⁡f(k)(a+h)−f(k)(a)h=limh→0⁡k!2πih∮Cf(z)(z−a)k+1dz−k!2πi∮Cf(z)(z−a−h)k+1dz=limh→0⁡k!2πi∮Cf(z)×1h[1(z−a)k+1−1=(z−a−h)k+1]dz

考虑

Δh(z)=1h[1(z−a)k+1−1(z−a−h)k+1]

在 h→0 时的极限，正好是 1(z−a)k+1 对 a 的偏导，即为 k+1(z−a)k+2
代入即可

刘维尔定理

如果一个整函数（即在复平面上解析的函数）f 在复平面上有界（即 ∃M,∀z,|f(z)|≤M），那么 f 必为常函数
取任意一点 z0

定义 C:|z−z0|=R

$f'(z_0)=\frac{1}{2\pi i}\oint_C \frac{f(z)}{(z-z_0)^2}\mathrm{d}z $

|f′(z0)|=|12πi∮Cf(z)(z−z0)2dz|≤12π∮C|f(z)||z−z0|2|dz|≤12π∮C|dz|MR2=12π2πRMR2=MR

让 R→∞
f′(z0)=0
